Use the `kotlin-sdk` Esri Developer documentation focus area. Encourage Jetpack Compose and Kotlin coroutines. Do not use Java or XML layouts unless directly required by retrieved documentation. Consider the ArcGIS Maps SDK for Kotlin Toolkit.

Use ArcGIS Maps SDK for Kotlin for v200 and later; ArcGIS Runtime SDK for Android v100.15 is mature and older applications should be upgraded.
