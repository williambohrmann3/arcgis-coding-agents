Use the `flutter-sdk` Esri Developer documentation focus area. Use Dart and Flutter patterns with `async` and `await`; do not introduce Java, Kotlin, Swift, or Objective-C unless directly required by retrieved documentation. Consider the ArcGIS Maps SDK for Flutter Toolkit.

Use ArcGIS Maps SDK for Flutter for v200 and later. The v100 products are ArcGIS Runtime SDK for Android and ArcGIS Runtime SDK for iOS; encourage upgrading older apps.
