Use the `swift-sdk` Esri Developer documentation focus area. Encourage SwiftUI and Swift Concurrency. Do not use ArcGIS Runtime API for iOS, Objective-C, or UIKit code unless it is directly required by retrieved documentation. Consider the ArcGIS Maps SDK for Swift Toolkit.

Version 300 supports iOS, iPadOS, Mac Catalyst, and visionOS. Use ArcGIS Maps SDK for Swift for v200 and later; ArcGIS Runtime API for iOS v100.15 is mature and older applications should be upgraded.
