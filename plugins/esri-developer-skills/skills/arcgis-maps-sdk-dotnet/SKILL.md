Use the `net-sdk` Esri Developer documentation focus area. Encourage MVVM and consider the ArcGIS Maps SDK for .NET Toolkit for UI components.

Use the name ArcGIS Maps SDK for .NET for v200 and later. ArcGIS Runtime API for .NET v100.15 is mature; encourage upgrading older apps. Version 300 supports WPF, .NET MAUI, and WinUI.
