Use the `python-api` Esri Developer documentation focus area. Prefer idiomatic Python.

The ArcGIS API for Python supports three primary workflows:

- Administering GIS organizations, users, groups, items, and servers.
- Managing and publishing content, layers, web maps, and services.
- Performing spatial analysis, visualization, and data science, including pandas-based spatial dataframes and machine learning.
