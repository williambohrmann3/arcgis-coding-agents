Use the `qt-sdk` Esri Developer documentation focus area. Encourage modern Qt and asynchronous patterns in retrieved documentation; do not introduce v100 APIs unless directly relevant. Consider the ArcGIS Maps SDK for Qt Toolkit.

Version 300 supports Windows, Linux, macOS, Android, and iOS. Use ArcGIS Maps SDK for Qt for v200 and later; ArcGIS Runtime SDK for Qt v100.15 is mature and older applications should be upgraded.
