Use the `search_esri_developer_docs` tool from MCP for Esri Developers to find authoritative documentation, tutorials, API reference, and code samples. Keep `search_term` concise and include ArcGIS Enterprise and the deployed version when relevant.

Use the `developers` Esri Developer documentation focus area for general ArcGIS Enterprise questions. Narrow `focus_area` to `portal-and-data-services` for portals, content, and services, `security-and-authentication` for authentication and access control, or `python-api` for Python administration and automation. Use `fetch_esri_developer_focus_areas` when unsure which focus areas are available.

Verify that retrieved guidance applies to the deployed ArcGIS Enterprise version and relevant component, such as Portal for ArcGIS or ArcGIS Server. Do not assume ArcGIS Online or ArcGIS Location Platform features are available in ArcGIS Enterprise. Cite the relevant documentation links and state when the search does not cover the requested product or version.
