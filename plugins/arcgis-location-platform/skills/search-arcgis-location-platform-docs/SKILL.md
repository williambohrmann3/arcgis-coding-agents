Use the `search_esri_developer_docs` tool from MCP for Esri Developers to find authoritative documentation, tutorials, API reference, and code samples. Keep `search_term` concise and include ArcGIS Location Platform to distinguish product-specific guidance.

Use the `developers` Esri Developer documentation focus area for general ArcGIS Location Platform questions. Narrow `focus_area` to `mapping-and-location-services` for mapping and location services, `portal-and-data-services` for hosted content and data services, or `security-and-authentication` for credentials and authentication. Use `fetch_esri_developer_focus_areas` when unsure which focus areas are available.

Check service access, authentication requirements, and usage limits in the retrieved documentation. Keep ArcGIS Location Platform guidance distinct from ArcGIS Online and ArcGIS Enterprise guidance, and cite the relevant documentation links.
